# R3 review: UI flows, keys, command menu (origin/plan-2 2f25faa, mock mode, headless chromium)
Screenshots: .scratch/review2/R3-*.png. Probe scripts: /tmp/r3/*.mjs

## Findings
### R3-1 Important: clicking "Add a description" opens the editor but does not focus it
where: ui/src/components/detail/Description.svelte:37 (onclick sets editing=true; textarea has no focus action)
what: the textarea appears, focus stays on BODY, so the next typed keys are shortcuts (HARD RULE: the key that opens an input must not leak). Typing `jk?` after the click opened the cheat sheet.
repro: mock, /issue/ABC-2, click "Edit description"/"Add a description", wait 500ms, document.activeElement is BODY; type `?` -> Keyboard shortcuts opens (R3-07 screenshot).
fix: autofocus the textarea when editing becomes true.

### R3-2 Minor: shortcuts fire behind the open "Add filter" menu
where: ui/src/components/ (filter bar Add filter dropdown, role=menu)
what: menu has focus on a div, not an input; typing j/k/x/s moves rows, selects and opens the status palette over the menu.
repro: /view/1, click "Add filter", press `s` -> Command palette opens.
fix: treat open role=menu as a modal scope for the key layer.

repro: /view/1, Cmd+K, type ABC-12, Enter, Esc, g i, Cmd+K.

### R3-4 Important: tooltips with the shortcut are missing on most buttons (spec: every button)
where: issue panel header, list toolbar, sidebar, row status, view tabs
what: hover (900ms) shows a tooltip only on New issue ("New issue c"), Keyboard shortcuts ("?"), Pin view (but no "." shortcut), theme. NO tooltip/title on: issue panel Previous/Next/Pin/Archive/Close/Copy key (shortcuts [ ] . # Esc mod+c), row status icon (s), Display/Sort/Group, Remove filter, "Add to <group>" (c), sidebar Pin buttons. fix: route all icon buttons through the existing Tooltip with the registry shortcut for their command id.

### R3-9 Minor: Cmd/ctrl-click on a row also opens the side panel

Screens R3-19/20. Selection state is visual only: rows have no aria-selected (checkbox span is role=presentation), so screen readers cannot tell which rows are selected.
