# R4 visual review, origin/plan-2 @ 2f25faa (mock mode, Vite). Shots: .scratch/review2/R4-shots/ (<theme>-<1440|1024>-<name>.png; st-* = states, x-* = extras)
Coverage: ~230 captures. Every route in both themes/sizes (views List/Board/Table/Timeline/Calendar month; saved views 2-4; issue page ABC-2/ABC-1; projects; views; cycles; pinned; my; inbox; all 12 settings sections; /design; first-run setup) and states (group-by status/project/priority; filter popover; display panel; side panel; right-click; quick add; command menu root/no results; cheat sheet; toast; new view; delete confirm; calendar week; CSV import + dry run). Light 1440 and dark 1440 opened one by one; the 1024 set opened for List, Table, Timeline, Calendar, issue, side panel, settings, setup, quick add (others glanced by tiling similarity, not each opened).
Overall verdict: reads as ONE designed product (forest-green frame, contour art, stone glyphs, band group headers are distinctive, not Linear-clone). It is calm and consistent in the main views. It falls down at the edges: settings, the small list pages, 1024 side panel, raw key names, and a few native-looking controls. Weakest three: (1) Settings (double headers, inconsistent page structure, rail height bug, raw-looking dropdown buttons), (2) Views / Projects / Cycles list pages (sparse, huge empty sheet, plain rows), (3) 1024 with the issue side panel open (broken layout).

## Important
- R4-01 1024 + side panel breaks layout. light-1024-st-side-panel-abc7.png (and dark). Title column disappears, filter chip wraps to 3 lines and clips ("Unst"), "New issue" clipped to "+", panel header wraps "ABC-/7" and the close X is cut off, Due/Estimate columns clipped. Repro: 1024x768, /view/1, click row, Enter. Fix: min list width / collapse panel to overlay below ~1100px, no-wrap header.
- R4-02 Table view at 1024 overflows: Labels column cut to "Lab" with the add-column "+" overlapping the header; tag chips clipped. dark-1024-v1table.png. Fix: horizontal scroll container with sticky first columns, or shrink Title.
- R4-03 Raw key names in UI. Right-click menu and cheat sheet and command menu show "mod+shift+z", "mod+d", "f2", "arrowdown", "escape", "mod+k" instead of glyphs (command/shift symbols) while the footer and search box use proper Kbd glyphs. light-1440-st-rightclick.png, light-1440-st-cheatsheet.png, light-1440-st-cmd-root.png. Fix: one formatter for registry keys to Kbd glyphs.
- R4-04 Cheat sheet dialog is taller than the 900px viewport and runs off the bottom (no max-height/scroll visible, last rows cut). light-1440-st-cheatsheet.png. Fix: cap dialog to viewport and scroll the body.
- R4-05 Side panel puts Details above the description; the description and sub-issues sit below the fold, the full issue page does the opposite. light-1440-st-side-panel-abc7.png vs light-1440-st-issue-abc7.png. Fix: same order in both.
- R4-06 Settings pages have two stacked h1s ("Settings" header, then "General"/"Statuses"...) and three different header structures: most sections use big h1 + rule; Templates and Import use a small icon+title row (+ tabs / button) at a different x offset (content starts x=529 on Import vs 513 elsewhere); Backups/Reminders/Calendar/Export put controls in rounded cards, Labels/Statuses/Properties are flat with a hairline. light-1440-set-*.png. Fix: one SettingsSection header component.
- R4-07 Settings left rail height follows content (ends at y=570 on most, 810 on Backups, 605 on General) leaving a hard cut bg block; and the whole settings page scrolls including the rail and the "Settings" header (dark-1440-x-import-dry.png shows rail scrolled up under the topbar). Fix: rail full height + sticky, scroll only the content pane.
- R4-08 Properties settings: "Select", "Number", "Date", "All projects" are bare outlined buttons with no chevron (look like labels/buttons, not dropdowns); "New option" input has no visible border, only placeholder text. light-1440-set-properties.png. Fix: use the Select primitive with chevron; bordered input.
- R4-09 Quick add chip "Due 2026-11-27" is ISO format while the rest of the app uses "Nov 27"; the contour art sits behind and collides with the title/chips; "p1" produced a "Low" priority chip (Linear convention is p1 = urgent; confirm intended scale, mock parser src/lib/api.mock.quickadd.ts:87). light-1440-st-quickadd.png.

## Minor

Table cell focus ring is a thick blue box; row focus elsewhere is signal red left edge. light-1440-v1table.png.
- R4-11 Timeline: "Today" flag overlaps the month/week header labels ("Nov 16", "Nov 23"); at 1024 the Soft launch diamond clips at the right edge; hatched bars are hard to read. light-1440-v1timeline.png, light-1024-v1timeline.png.

- R4-20 Display panel hugs/overflows the right edge of the window (no gutter) and covers the footer; popover for Group is a lone select in a big white box (poor, no preview/ordering). light-1440-st-display-panel.png, light-1440-st-group-menu.png.
- R4-21 Toast: bell icon for every message ("Updated issues", "Changed view", "Nothing to undo"); display changes (grouping) create an undo toast, which is noise; "Undo (cmd+Z)" spelled out as text, not glyphs. light-1440-st-toast.png, dark-1440-x-group-project.png. (Known list covers persistence/labels.)
- R4-22 Icon inconsistencies: project icon is a circle on issue page/detail rows but a mountain in sidebar/lists; command menu uses folder for Projects, board icon for Views, layers for Design gallery; Properties and "All projects" share layers; Templates and label "Docs" share bookmark. light-1440-issue.png, light-1440-st-cmd-root.png.

- R4-24 First-run setup: layout imbalanced (hero text vertically centred far left, card far right, big empty top); Theme row uses underline tabs unlike every other control. light-1440-setup.png.
- R4-25 General settings: blank Workspace name field with no placeholder (Export directory, Git remote, Backup directory also blank, no placeholder/hint). light-1440-set-general.png, dark-1440-set-export.png. Status pill style differs between Calendar ("Not connected" pill), Reminders and Export (plain dot).

- Dark mode: no misses seen beyond light-only art; toast inverts to light in dark (fine).
- No insights panel or charts exist in this build; nothing to review.
