# R5 review: points and progress charts (origin/plan-2 @ 7e82b41)
Shots: .scratch/review2/R5-shots/. Time box about 40 min; coverage below is partial.

## Findings
**R5-1 Important** crates/core/src/quickadd.rs (client: ui/src/components/QuickAdd.svelte:72,108). With estimation = none or time, quick add still saves points. The chip is hidden, but the `3pt` token is removed from the title and points are stored.
Repro: devserver on a seeded db, `settings_set estimation none`, in the app press `c`, type `qa-none hidden 3pt`, Enter. `taskapp issue search qa-` then shows ABC-25 "qa-none hidden" points 3.0 (and ABC-26 for time). Shot: quickadd-none.png.
Fix: when points are off, do not parse or send points (leave the token in the title).

**R5-2 Important** ui/src/components/ViewEditor.svelte:67, ui/src/components/display/types.ts pointsName/pointsTotal, TableView/ListView/BoardView group and column code. With estimation none/time, the Group-by and Sort-by menus still offer "Points". A view saved with Points group or column still shows "5 points" group headers and a "Points" column header (values blank).
Repro: save view 1 with group_by Fixed Points, columns Title+Points, estimation none, open /view/1/Table (also List, Board). Shots: pts-none-Table.png, pts-time-List.png, Group-menu-none.png. Option lists printed via Playwright: `Group by` options include "Points" for none and time.
Fix: filter Points out of allFields when !pointsOn, and ignore a Points group_by/column when off. No test covers this (only the row and quick-add chip are tested).

**R5-3 Important** crates/core/src/issues.rs:151 valid_points. No upper bound and the one-decimal check has a 1e-6 tolerance on tenths. Accepted via core, CLI and quick add: 1e20, 1e300, 1e-7, 9e-8, 0.30000000000000004 (0.1+0.2). `3.04999999` is refused.
Repro: `taskapp --db X issue create t --points=1e20` and `--points=0.0000001` both succeed; `quickadd::parse("fix 99999999999999999999pt")` gives Some(1e20). Rejected correctly: -1, 0.25, NaN, 1e400 (inf), abc (clap).
Fix: cap (e.g. 10000) and require `(p*10).round()/10 == p` exactly, or store tenths as integers.

**R5-4 Minor** quickadd.rs:213. `3 pt`, `3pts`, `.5pt` and `3.pt` are not recognised and stay in the title (`3pt`, `0.5pt`, `pt3`, `3PT` work). Fine if intended; the brief listed `3 pt` and `3pts`.

**R5-5 Minor** crates/core/src/insights.rs progress_on. `to < from` returns "range ... must be 1 to 1100 days" (misleading for a reversed range).
Repro: `taskapp insights progress --project 1 --from 2026-12-31 --to 2026-01-01`.

**R5-6 Minor** ui Cycles page at 1024 px: the "Move unfinished to next cycle" button is clipped at the panel's right edge (cycles-1024-dark.png).

**R5-7 Minor** palette "Set points..." is still listed when points are off (it leads to a "Points are off" item). Acceptable if by design.
