# U4 Board view   (owns ui/src/components/views/BoardView.svelte and its test)
- Columns per status (or the view's group-by) with a legend-band column header (count, add), cards (key, title, PriorityGlyph, labels, project icon, due), faint contour art only in empty columns. Drag a card between columns and within a column (keyboard alternative: commands move card left/right, defined by another task; expose column order + ids via the selection store). Focused card = signal outline; multi-select works like the list.
- Collapsed columns (Done/Canceled collapsed by default, persisted), hidden empty columns option, horizontal scroll with sticky headers.
Tests: drop changes status and calls the api once; focused/selected state; collapsed persists; empty column state.
