# U2 View page header and view editor   (owns ui/src/app/ViewPage.svelte, components/ViewEditor.svelte, components/filters/**)
- PageHeader with the view's icon and name (inline rename), layout Tabs (List, Board, Table, Timeline, Calendar; keys 1-5 as commands in defs/view/), filter chips (status, status category, project, labels, priority, due, custom properties: add, edit, remove; each chip is a Popover editor), Group by and Sort menus, display options, 'New issue' CommandButton (c).
- Saving: changes to filters/layout/grouping update the saved view (debounced) with a 'Save as new view' action; pin view; delete view (confirm Dialog).
- Renders the chosen layout component with the filtered issues; empty result = EmptyState with 'Clear filters'.
Tests: switching layout renders that view and persists; adding a status-category filter narrows results (mock AND contract-shaped data); rename persists; keys 1-5 switch layout.
