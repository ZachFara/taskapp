# U20 Template editor   (owns ui/src/components/settings/Templates.svelte and its test)
- List of templates (EntityIcon, name, slug as '/slug') and an editor: name, slug (validated), IconColorPicker (import from components/pickers; if it is not on your branch yet use a temporary TextInput for icon and Select for colour behind the same value shape and say so), title prefix, description, status, priority, project, labels, estimate, custom properties, sub-issues (ordered list of titles, add/remove/reorder). 'Try it' creates an issue from the template. Delete with confirm.
Tests: create/update/delete call the api once with the right body; slug validation; sub-issue reorder; try-it calls apply.
