# U14 Cheat sheet and CommandButton   (owns ui/src/components/CheatSheet.svelte, components/CommandButton.svelte and tests)
- CheatSheet: opened by the `help.shortcuts` command (?). A Dialog listing EVERY command with a shortcut, grouped by `groups()`, generated from the registry (no hand-written list), filter field at the top, sequences shown as separate Kbd keys ('g' then 'i'), two or three columns, Esc closes.
- CommandButton: props { command: id, variant, iconOnly }. Renders a Button/IconButton whose label, icon, disabled state (`when`) and Tooltip (action name + shortcut, hover delay from tokens, also on keyboard focus) come from the registry, and whose click runs the command with the live ctx (ctx from a Svelte context that App provides: `getContext('cmdctx')`; fall back to a no-op ctx in tests).
Tests: sheet lists a newly registered test command with its keys; filter narrows; CommandButton tooltip shows label and shortcut; click runs; hidden/disabled when `when` is false.
