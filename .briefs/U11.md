# U11 Settings: entities and the icon/colour picker   (owns ui/src/components/settings/{Statuses,Labels,Projects,Cycles,Properties}.svelte, ui/src/components/pickers/** and tests)
- `pickers/IconColorPicker.svelte`: a Popover with the icon set (searchable grid from Icon ids), an emoji tab (a small built-in list by category plus paste-any-emoji), and the 12 palette colours as swatches; value = { icon: 'icon:<id>'|'emoji:<x>'|null, color: <key>|null }. Used in every settings list here and exported for views and templates.
- Each settings screen: a real table/list on the sheet (no cards), inline rename, picker, drag to reorder where order matters (statuses within category), add row, delete with confirm Dialog (statuses: choose where issues move), category sections for statuses as legend bands, property definitions with type-specific options (select options editor).
Tests: picker emits the right value shape; rename/reorder/delete call api once; status delete requires a target; property select options edit.
