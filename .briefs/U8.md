# U8 Issue detail panel   (owns ui/src/components/IssueDetail.svelte, components/detail/** and tests)
- Side-panel and full-page (/issue/:key) modes share one component. Header: project icon, key (copy on click), prev/next, close. Title inline edit. Description: markdown (marked + dompurify, existing) with edit/preview. Properties block: status, priority, project, milestone, cycle, labels, start, due, estimate, parent, every custom property; each row is an inline editor (Menu/Popover/date picker) and shows its shortcut via Kbd. Sub-issues with progress and quick add. Relations (blocks, blocked by, related, duplicate) with IssuePicker. Comments. Activity (history) as dated entries. Pin and archive actions. Created/updated meta.
- All editors are primitives; faint contour art allowed only in the panel's empty areas.
Tests: each property edit calls the api once and shows the new value; markdown is sanitised (script tag test); sub-issue add; relation add/remove; Esc closes editors before the panel.
