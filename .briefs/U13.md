# U13 Command menu   (owns ui/src/components/CommandPalette.svelte and its test)
- Opens with mod+k and mod+p (commands exist). A centred panel on the overlay (Dialog primitive), square-cornered, the look of the spike's palette.html: query field, grouped results with icon, label, group hint, shortcut right-aligned (Kbd).
- Sources, ranked with match.ts + recents: commands from `listCommands(ctx)` (contextual ones for the selection / open issue FIRST with a header like '3 issues selected'), issues (key and title; api search), views, projects, cycles, labels, settings pages, recent items.
- Nested pages: a command with `page` opens a sub-list (breadcrumb chip in the field, e.g. 'Set status'); Backspace on an empty query goes back up; Esc closes one level then the menu. Multi-pick pages (labels) keep open with checkmarks. Free-input pages (due date parsed from text like 'fri', 'nov 28', '+3d'; estimate '2h') show a preview row.
- Keyboard: up/down, ctrl+n/p, ctrl+j/k, enter, tab completes; mouse hover highlights; never loses focus; results list is a proper listbox for screen readers; empty state.
- Running a command on a selection applies to all selected issues (the command's run receives ctx.selection).
Tests: contextual commands first; nested page and Backspace; Esc levels; issue search result navigates; shortcut shown from registry; multi-pick.
