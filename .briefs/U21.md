# U21 Undo and redo in the UI   (owns ui/src/lib/commands/defs/history/**, ui/src/components/UndoToast.svelte and tests)
- Commands: history.undo (mod+z, and u), history.redo (mod+shift+z, and ctrl+r as a second binding only if it does not clash), both `global: true` for mod combos but never while a text field has its own undo to do (in a text field mod+z must stay native). Labels come from undo_status ('Undo Set status on 3 issues').
- UndoToast: after any command that wrote, a Toast 'Set status on 3 issues · Undo (cmd+Z)' for 6 seconds; clicking Undo runs it; after an undo: 'Undone · Redo'. A refused undo (conflict) shows the error text from the backend in the toast.
- Refresh stores after undo/redo so every view updates.
Tests: mod+z in a text field does not run the command; outside it calls undo once; toast shows the step label; conflict error shown; redo after undo.
