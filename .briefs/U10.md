# U10 Cycles, Pinned and index pages   (owns ui/src/components/{CyclesPage,PinnedPage,MyIssuesPage,InboxPage,ProjectsPage,ViewsPage}.svelte and tests)
- Cycles: current cycle first (dates, days left, progress, scope), upcoming, past (collapsed); a cycle opens its issues in the shared ListView; create cycle; move unfinished issues to next cycle (confirm).
- Pinned: pinned views, projects and issues in three groups with legend bands, unpin, reorder; designed EmptyState with contour art ('Nothing pinned yet').
Tests: current/upcoming/past grouping with an explicit date; move unfinished calls api once; unpin; empty state.
- My issues (/my): all open issues in the shared ListView, grouped by status (single-user app: "my" = everything not archived, not done).
- Projects (/projects): table of projects (EntityIcon, name, progress, target date, issue counts), 'New project', link to the all-projects timeline.
- Views (/views): saved views (icon, name, layout, pinned), 'New view', delete with confirm.
- Inbox (/inbox): a designed EmptyState only ("Inbox arrives in a later release"); the inbox feature is out of scope.
