# R4 Visual review against the design system, every screen, both themes, two sizes   (ID: R4)
Area: every screen. Read docs/design-system.md, ui/src/styles/tokens.css and <claude-home>/skills/design-taste-frontend/references/app-screens.md sections 3, 4, 7, 8, 9, 10, 11, 13, 14.
Method: start Vite in mock mode on a free port (`VITE_API_MODE=mock pnpm -C ui exec vite --port <free> --strictPort`) and capture with Playwright (see <workspace>/taskapp/.scratch/walk3/walk3.ts) EVERY route and state, in light and dark, at 1440x900 and 1024x768, into your scratch folder; open every image with the Read tool. Routes and states: /, each saved view in List, Board, Table, Timeline, Calendar (month and week); a grouped list by project/priority/cycle/label; an empty filtered view; the issue side panel and the full issue page (with sub-issues, relations, comments, long description); project page; projects, views (with templates), cycles, pinned (empty and with pins), my issues, inbox; every settings section (general, statuses, labels, projects, cycles, properties, templates, import with a CSV loaded and the dry-run result, reminders, calendar, export, backups); quick add with chips; command menu root, a nested page, no results; cheat sheet; right-click menu; display panel; new view dialog; delete confirmations; toasts; first-run setup; the /design gallery; the insights panel and charts if present.
Judge each against the design system and the owner's brief ("be very bold; Linear's interaction patterns, not its visual identity; calm and fast; real headers; proper group headers; styled controls, no browser-default buttons or inputs; designed empty states"). Report: anything that looks unfinished, default, misaligned, clipped, overflowing, inconsistent between screens (spacing, type sizes, icon sizes, radii, header structure), low contrast (measure it), a native control, a hard-coded colour that slipped past the token check, dark-mode misses, 1024 px breakage. For each finding name the screenshot file. Also give a short overall verdict: does it read as one designed product, and which three screens are weakest.
