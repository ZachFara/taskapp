## What
External links (project "Open in Obsidian" button, url/note pins on the Pinned page and in the Sidebar) open in the
system handler inside the desktop app, and in a new tab in the browser harness.

## Steps
1. Add `@tauri-apps/plugin-opener` (pnpm, in ui/) and `tauri-plugin-opener` (pin an exact version in the root
   Cargo.toml `[workspace.dependencies]`, use `workspace = true` in app/src-tauri/Cargo.toml). Register the plugin in
   app/src-tauri/src/lib.rs. Add `opener:allow-open-url` for `obsidian://*`, `https://*`, `http://*` only to the app
   capability file.
2. New `ui/src/lib/openExternal.ts`: `openExternal(url)` refuses anything not starting with `obsidian://`, `https://`
   or `http://` (returns false); in Tauri (`'__TAURI_INTERNALS__' in window`) calls the opener plugin's `openUrl`,
   otherwise `window.open(url, '_blank', 'noopener')`. Test file `openExternal.test.ts`: refuses `javascript:` and
   `file:`; uses window.open outside Tauri. Write the tests first and watch them fail.
3. Replace the `window.open` calls in ProjectPage, PinnedPage and Sidebar with `openExternal`. Their existing tests
   must still pass.
4. `pnpm -C ui test`, `pnpm -C ui build`, `scripts/gate.sh`, commit, push, PR into plan-1, wait with
   `gh run watch <id> --exit-status`.
